# 🌌 Neon Word Clock

A sleek, interactive, and fully responsive **Word Clock** featuring a custom sci-fi neon aesthetic, dynamic color themes, and smooth hover effects.

🔗 **Live Demo:** (https://boberisintelligent.github.io/Clock/)

# ✨ Features

- **11x11 Grid Word Matrix:** Accurately highlights the current time in words (e.g., *"IT IS HALF PAST SIX"*).
- **Interactive Hover System:** Hover over any letter to inspect associated words and time blocks via dynamic tooltips.
- **Custom Neon Theme Picker:** Switch between multiple glowing neon color accents on the fly.
- **Custom Font Rendering:** Integrated local **Orbitron** font for crisp, futuristic typography across all platforms.
- **Dual Time Display:** Combines a classic textual word clock layout with a clean digital backup and ambient background glow.
